## 目录结构规范

- **一级目录**：一律采用培养方案官方课程中文全称平铺（共 37 门课程）。
- **二级目录**（按需创建，无文件则不建空目录）：
  - `期中/`：期中笔试/开闭卷真题与解答
  - `期末/`：期末真题、回忆版与解答
  - `机试/`：上机编程考试真题（如问题求解系列）
  - `资料/`：考前 CheatSheet、随堂小测/摸底测试、真题合集或说明文档（不含平时作业与大部头教材）

## 命名模板

`<课程简称>-<YYYY>[秋|春]-<阶段>[（层次/班型/教师/学院）]-<试题|答案|试题及答案>[（版本/形式）].<ext>`

- **开课学年学期年**：以该门课程**实际开课学期**为准——秋季学期（9 月开课，次年 1 月考试）记 `YYYY秋`；春季学期（2 月开课，6–7 月考试）记 `YYYY春`；卷面无季节信息仅记年份者为 `YYYY-`，完全缺失年份者记 `未知年份`。
- **常用简称**：`ICS`（计算机系统基础）、`OS`（操作系统）、`计网`（计算机网络）、`数逻`（数字逻辑与计算机组成）、`SICP`（计算机程序的构造和解释）、`问求1~4`（问题求解一至四）、`微积分1/2` 等。
- **跨学院标注**：保留的软件学院、人工智能学院、商学院等同期试卷已在括号中明确标注学院名称。

## 收录边界与后续维护规范

1. **收录与不收录红线**
   - **本仓收录**：期中 / 期末 / 机试真题（含原卷、回忆版、参考答案）、考前 CheatSheet 与随堂摸底测验；跨学院同期同类试卷可收录，但必须在括号内标明学院。
   - **不收录**：平时作业、实验报告（Lab）、大部头教材 PDF、OJ 专题课件、推免及非 CS 通识背诵资料。
2. **新增真题与重命名自检**
   - **先查重、核题干，再入库**：严禁仅凭文件名直接判定配套或重复（历史上曾出现“同名文件实为两套不同试卷”、“期中文件名实为期末卷”、“24fall 实为 23fall”等错名坑），新增前务必核对首页标题与前两题内容。
   - **多年份合集按年拆分**：如遇多年合订 PDF，优先按页无损拆分为逐年单卷后再入库（禁止修改原卷题面）
   - **纯重复淘汰，有增量双留**：完全同卷的低质 / 广告 / 公式缺失 / 错译版本直接淘汰；若各具增量（如原卷扫描 vs 重排复刻版、纯试题 vs 个人解答版、`.md` vs `.pdf`），双留并用末尾括号后缀区分，避免覆盖。
3. **提交格式与体积约束**
   - 新增课程直接平铺建于根目录，**目录名用官方中文全称**，仅创建有文件的二级目录（`期中/`、`期末/`、`机试/`、`资料/`），不留空文件夹。
   - 单文件体积保持在 **50 MB 以内**；不要直接上传 `.zip`/`.rar` 等大体积打包压缩文件。
